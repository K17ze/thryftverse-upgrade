# Accessibility, Input and Motion

## Touch targets

Project standard:
- 44pt minimum interactive area;
- 48pt preferred for high-frequency controls.

Audit every creative surface, including visually 40px drawing controls.

## Drag alternatives

Provide non-drag alternatives for:
- layer move;
- z-order;
- frame reorder;
- timeline trim;
- timeline seek;
- gradient stop position;
- exact rotation/scale where precision matters.

## Screen readers

Each tool exposes:
- label;
- selected state;
- disabled state;
- current value for sliders;
- increment/decrement actions.

## Color accessibility

The professional color picker provides exact text/numeric input so color selection is not purely spatial. Announce swatch names/HEX and current value.

## Motion

Reduce Motion:
- no parallax;
- no large morph/zoom;
- no repeated decorative pulse;
- preserve state via fade/crossfade.

Do not automatically disable useful haptics solely because Reduce Motion is enabled; tactile and visual motion preferences are separate dimensions.

## External keyboard / tablets

Retain and improve existing shortcuts:
- visible help sheet;
- focus rings;
- tab order;
- arrow nudge;
- delete/duplicate;
- timeline stepping.

## Captions

Video accessibility path should include generated captions, edit, timing and style.

## Non-color state

Selection, error and upload state need shape/icon/text in addition to color.
