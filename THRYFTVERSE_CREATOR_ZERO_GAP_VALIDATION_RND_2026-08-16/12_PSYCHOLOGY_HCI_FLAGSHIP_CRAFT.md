# Psychology and HCI — What Makes a Creator Feel Flagship

## Recognition over recall

A visual decision should be represented visually:
- font with user's words;
- filter on user's media;
- layout using user's objects;
- transition preview;
- exact color swatch.

## Direct manipulation

Primary loop:
`touch content → manipulate → local/context controls → commit`.

Avoid:
`choose abstract mode → fill form → close → inspect result`.

## Progressive disclosure

The first surface exposes only likely next actions. Precision appears after selection. This is the main cognitive difference between a mature creative instrument and a feature menu.

## Reversibility

Users explore when:
- undo works;
- source media is nondestructive;
- autosave is trustworthy;
- effects preview truthfully;
- a crash won't erase the project.

## State legibility

The editor must always answer:
- what is selected?
- which tool is active?
- what will this gesture change?
- where is the playhead?
- is the project saved?

This is why the missing active state in ContextToolRail is not merely visual polish.

## Perceptual continuity

Routine edits should not replace the canvas with form screens. Precision panels should leave enough canvas visible to understand cause/effect.

## Feedback hierarchy

- press → visual + light haptic;
- snap → light threshold haptic;
- reorder landing → medium;
- destructive commit → stronger;
- publish success → restrained.

Do not use identical haptic strength for every tap.

## Motor fluency

- 44–48pt targets;
- no artificial long-press delay for normal navigation;
- predictable gesture arbitration;
- sliders react from where the thumb actually is;
- resize/rotate feels continuous.

## Safe default

The zero-edit output should look good. Particularly in Look, a user selecting several images should immediately get a coherent result.

## Content-first hierarchy

Premium is not gold/blur/glass. It is:
- strong media dominance;
- optical spacing;
- consistent icon weight;
- useful motion;
- reliable output;
- quiet chrome.

## Muscle memory

Pinned tools are user-driven. Do not silently reorder primary tools based on analytics every session.

## Trust through truth

A tool that lies is more damaging than a missing tool:
- fake filter preview;
- static “AI” preset;
- Cutout without cutout;
- resume that restarts;
- keyframe editor whose output isn't evaluated.

**Truth is a UX property.**

## Delight

Use delight at meaningful physical moments:
- snap;
- selection lift;
- timeline trim boundary;
- cutout reveal;
- layout morph.

Avoid decorative animation for its own sake.
