# Look — Collage + Commerce Zero-Gap Specification

## Product advantage

Look should not imitate Stories. Its differentiated target is a **shoppable editorial composition instrument**.

## Current strengths
- dedicated Look composer;
- spatial canvas;
- layout alternatives;
- product source tray;
- multi-select foundations;
- background tools.

## Remaining gaps
- very large composer orchestration;
- background Image option is not actually live;
- fragmented color system;
- production cutout unavailable in standard build;
- canonical canvas does not render mask/effect stack;
- product drag/placement polish requires device proof;
- publication quality is not yet device-verified.

## 1. Successful default

Selecting 2–6 assets should immediately produce a publishable composition:
- balance source aspect ratios;
- sensible crops;
- strong spacing;
- one dominant focal point;
- live visual alternatives.

No blank manual-assembly penalty.

## 2. Layout previews

Render actual user objects in choices:
- Editorial;
- Hero;
- Grid;
- Stack;
- Scatter;
- Magazine;
- Minimal;
- Product Focus.

Temporary press/scrub can preview without committing; tap commits one history operation.

## 3. Commerce source drawer

Collapsed:
- 3 recent/saved/listed items.

Expanded:
- Closet;
- My Listings;
- Saved;
- Discover/Search.

Allow direct drag from source drawer onto canvas. Drop location is the object's initial placement.

## 4. Product object presentation

Offer modes:
- invisible hotspot;
- tiny tag;
- image chip;
- price chip;
- editorial label.

Commerce should not make every Look look like a marketplace card.

## 5. Product truth

Sold/deleted listings:
- keep composition visually intact;
- show status on interaction;
- disable purchase;
- never create a broken layer.

## 6. Background

Complete the actual feature set:
- solid exact color;
- custom gradient;
- blurred selected media;
- chosen image;
- media sampled color;
- transparency only when output supports it.

Remove or implement the currently disabled Image tab.

## 7. Multi-select

Support:
- select multiple;
- group;
- align;
- distribute;
- group scale/rotate;
- duplicate;
- front/back;
- delete.

## 8. Overlap selection

Repeated tap cycles candidates. Long-press can show a compact local stack. Global Layers stays advanced.

## 9. Smart assistance

Optional and reversible:
- subject crop;
- true cutout;
- layout suggestion;
- palette harmony;
- equal spacing;
- alignment.

## 10. Publish fidelity

Published Look must preserve:
- masks;
- effects;
- exact text;
- exact color;
- ordering;
- background;
- product anchors.

The renderer, not a narrowed serializer, should be authoritative.
