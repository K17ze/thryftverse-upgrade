# MASTER PROMPT — Thryftverse Phase 4 flagship art-direction reconstruction

You are not performing a generic “UI polish” pass.

## Mission

Reconstruct Thryftverse's visible product composition so it feels authored, human, current, platform-native and production-grade while preserving truthful commerce/financial/agent behavior.

## Mandatory inputs

Read:
- `AGENTS.md`
- `Design.md`
- every document in this Phase 4 folder
- current target source files
- latest remote Phase 3.1 commits
- current native screenshots when available

## Absolute constraints

1. Do not undo Phase 3.1.
2. Do not fabricate unavailable capabilities.
3. Do not change financial/auction/Co-Own truth merely to simplify UI.
4. Do not create generic shared cards to make implementation faster.
5. Do not add decorative gradients/glass/gold as “premium.”
6. Do not label ordinary assistance as AI.
7. Do not expose internal architecture terminology to users.
8. Do not claim visual completion without native captures.
9. Do not execute one monolithic 100-file “polish” commit.

## Visual north star

Content should visually win over chrome.

The interface should rely on:
- imagery;
- typography;
- negative space;
- contextual actions;
- native motion;
- flat grouping;
before using:
- cards;
- pills;
- badges;
- gradients;
- icon circles.

## Required process per department

### Audit
Write:
- current first viewport;
- all permanently visible controls;
- all cards/pills/badges;
- duplicated labels;
- internal/system statuses;
- state variants.

### Recompose
Define:
- dominant object;
- primary action;
- secondary action;
- progressive disclosures;
- content role;
- media geometry.

### Implement
Prefer existing primitives when they match the role.
Delete/simplify primitives that exist only to create repeated dashboard grammar.

### Verify
- typecheck;
- relevant tests;
- residue;
- accessibility;
- native screenshots;
- compact + expanded if affected.

## Definition of done

A department is done only when:
- behavior remains truthful;
- the screen has an obvious attention hierarchy;
- the first viewport is not a feature inventory;
- card/pill counts are justified;
- copy is concise;
- motion explains state;
- native screenshots meet the Phase 4 rubric.

Return an implementation report with:
- starting/final SHA;
- files changed;
- before/after hierarchy;
- deleted visual debt;
- behavioral invariants preserved;
- tests;
- screenshot paths.
