# Metrics and experimentation

Phase 4 should not optimize aesthetics blindly.

## Home
- open rate by tile role;
- save rate;
- long dwell;
- hide/not interested;
- seller-profile detour;
- scroll depth.

## Search
- time to first result;
- reformulation;
- filter use;
- no-result rate;
- result open;
- visual-search conversion.

## Product
- gallery depth;
- seller trust expansion;
- offer start;
- buy start;
- Q&A open;
- purchase completion.

## Sell
- time to first draft;
- abandon field;
- media count;
- publish success;
- suggestion accept/edit;
- return-to-draft completion.

## Auction
- Live scope open;
- watch;
- bid-sheet open;
- bid success;
- outbid recovery;
- filter usage.

## Creator
- camera-to-capture;
- selected-media count;
- time to first edit;
- publish;
- abandon;
- use of advanced tools.

## Profile/Closet
- saved revisit;
- collection creation;
- follow/message;
- profile edit.

## Experiments
Run compositional experiments, not color-button experiments first:
- metadata-dense vs media-dominant feed;
- 4 Explore modes vs 3;
- Closet stats default vs Insights;
- Auction 5 header actions vs reduced header;
- seller analytics card grid vs outcome/trend layout.

Guardrails:
- accessibility;
- transaction success;
- trust complaints;
- search relevance;
- support contact rate.
