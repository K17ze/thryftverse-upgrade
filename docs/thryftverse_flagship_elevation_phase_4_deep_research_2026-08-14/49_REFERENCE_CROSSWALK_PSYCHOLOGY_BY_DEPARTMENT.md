# Reference crosswalk — what to borrow, what NOT to borrow

The goal is not to clone Pinterest, Instagram, Depop, eBay, Vinted, Snapchat or Whatnot. It is to understand why specific behaviors feel mature.

---

# Pinterest

## Borrow
- media dominance;
- masonry rhythm;
- collections/boards as visual objects;
- image as search input;
- discovery before query;
- composition tools sourced from saved/shoppable objects.

## Don't borrow blindly
- exact pin card dimensions;
- brand red;
- consumer inspiration terminology where Thryftverse needs transaction clarity.

## Apply to
- Home;
- Explore;
- Closet/Collections;
- Look;
- Visual Search;
- Galleria.

---

# Instagram

## Borrow
- predictable identity hierarchy;
- simple bottom navigation;
- flat inbox rows;
- creator/viewer media dominance;
- context-sensitive creation;
- low-chrome capture.

## Instants lesson
A deliberately constrained creation path can feel more human than an everything-editor.

## Don't borrow
- engagement-first metrics where commerce trust should lead;
- exact social grammar for financial Co-Own.

## Apply to
- Profile;
- Inbox;
- Chat;
- Poster;
- Camera.

---

# Snapchat

## Borrow
- tap/hold capture;
- Multi Snap review model;
- temporal timeline only for temporal media;
- direct full-screen editing;
- tool disclosure.

## Don't borrow
- highly playful icon density;
- lenses/discoverability patterns that don't fit luxury commerce.

## Apply to
- Camera;
- Poster;
- video editing.

---

# Depop

## Borrow
- seller/social commerce blend;
- concise fashion listing;
- draft continuity;
- sold-comparable price guidance;
- query relevance.

## Don't borrow
- limitations in media count if Thryftverse can support more robust evidence;
- exact visual youth-culture styling if brand aims broader luxury.

## Apply to
- Product;
- Sell;
- Search;
- seller profile.

---

# Vinted

## Borrow
- structured ontology;
- condition honesty;
- flaw/evidence prompts;
- many informative photos;
- filter/query relevance.

## Don't borrow
- utilitarian visual density on editorial discovery.

## Apply to
- Sell;
- Product trust;
- Search/filter.

---

# eBay

## Borrow
- deep filtering;
- comprehensive media/video;
- seller operational depth;
- buying format clarity.

## Don't borrow
- expose full desktop marketplace complexity on mobile first viewport.

## Apply to
- Search;
- Product;
- Seller;
- Auction.

---

# Whatnot

## Borrow
- auction focus on current bid/time/action;
- real viewer bid state;
- pre-bid/max bid concepts where supported;
- clear countdown rules.

## Don't borrow
- livestream-first energy if auction is asynchronous/non-live;
- constant urgency styling for long auctions.

## Apply to
- Auction.

---

# Apple HIG 2026

## Borrow
- semantic search/tab concepts;
- navigation vs action distinction;
- Liquid Glass as control/navigation layer;
- minimal toolbars;
- adaptive platform behavior.

## Don't interpret as
“make everything look like Apple.”

Thryftverse still needs own visual language.

---

# Android 2026

## Borrow
- adaptive navigation;
- edge-to-edge;
- one high-priority action;
- grid/pane changes on larger devices;
- semantic containment.

## Don't do
iOS layout copied pixel-for-pixel to Android.

# Core instruction

Borrow **the reason** a reference works:
- hierarchy;
- proximity;
- feedback;
- cognitive load;
- visual rhythm.

Do not borrow:
- exact brand appearance;
- terminology;
- copyrighted imagery;
- idiosyncratic components with no Thryftverse job.
