# Phase 4 execution roadmap

Do not execute this as one giant refactor.

## Pass 0 — Evidence freeze
- fetch real Phase 3.1 HEAD;
- run typecheck/tests/residue;
- capture pre-change screenshots where possible;
- freeze behavior contracts.

## Pass 1 — Global optical laws
Implement:
- visibility/card/pill budgets;
- flat-row primitive;
- material discipline;
- typography roles;
- motion reductions.

Do not restyle every screen yet.

## Pass 2 — Navigation + Explore + Search
Highest cross-app leverage:
- Create semantics;
- Explore taxonomy;
- global search continuity;
- filter model;
- adaptive navigation.

## Pass 3 — Home + Saved/Closet
Rebuild visual discovery rhythm and personal curation surfaces.

## Pass 4 — Product + Sell
Buyer/seller conversion surfaces.

## Pass 5 — Auction
Home lifecycle hierarchy then Detail/bid sheet.

## Pass 6 — Co-Own/Galleria
Clarify editorial vs market; upgrade evidence dossier.

## Pass 7 — Profile + Settings
Owner/public identity and flat account architecture.

## Pass 8 — Inbox + Chat + Agents
Remove segmentation/chip noise; add contextual agent/session UI over frozen broker semantics.

## Pass 9 — Creator
Acquisition chrome, Poster polish, Look source tray/direct manipulation.

## Pass 10 — Wallet/Checkout/Orders/Seller/Notifications
Calm transaction/operations surfaces.

## Pass 11 — Adaptive + accessibility
Medium/large Android, landscape, large text, reduced motion/transparency.

## Pass 12 — Native screenshot sign-off
No Phase 4 “complete” claim before screenshots.

## Commit discipline
One commit per coherent user-visible contract.
Required commit message includes:
- route(s);
- old hierarchy;
- new hierarchy;
- behavior preserved;
- screenshot IDs/tests.

Avoid “flagship polish” commits that touch 100+ files without a visual acceptance artifact.
