# Screen-by-screen first viewport specification

This is a brutal practical test: what is allowed before the first scroll?

---

## Home
Allowed:
- compact header;
- one social pulse lane if content exists;
- feed media.

Not allowed:
- multiple section titles;
- multiple rails;
- stats;
- tutorial card.

## Explore
Allowed:
- Explore title;
- Search;
- visual-search icon;
- one scope control;
- first discovery media.

## Global Search idle
Allowed:
- focused/available field;
- Recent;
- Browse categories/visual suggestion.

## Search results
Allowed:
- field;
- scope;
- Filter/Sort;
- first row/grid.

## Closet
Allowed:
- Saved/Collections;
- visual saved grid/board covers.
Price-drop cue only if present.

## Product
Allowed:
- media stage only, then identity begins as user scrolls.
Floating back/share/save.

## Sell
Allowed:
- close/back + Sell title;
- media studio;
- first item identity fields.

## Auction Home
Allowed:
- title/search/filter;
- lifecycle scope;
- attention if real;
- live content.

## Auction Detail Live
Allowed:
- media;
- price/time/my-state/action by 1–1.5 viewport.

## Co-Own Hub
Holder:
- header;
- positions.
Nonholder:
- market highlight/education only if needed.
Then scope/market.

## Galleria
Allowed:
- title/header;
- editorial hero.

## Asset Detail
Allowed:
- media;
- title;
- issuer;
- per-unit price;
- availability.

## Due Diligence
Allowed:
- title/asset;
- first evidence section.

## My Profile
Allowed:
- cover/avatar;
- identity;
- social;
- owner utility minimal;
- tabs begin.

## Public Profile
Allowed:
same identity + Follow/Message.

## Settings
Allowed:
- title/search;
- optional identity row;
- first 2 settings groups.

## Inbox
Allowed:
- title;
- search;
- 3 scopes max;
- messages.

## Chat
Allowed:
- top identity;
- listing context if relevant;
- messages;
- composer.

## Connections
Allowed:
- title/security subtitle;
- provider list begins.
No required hero.

## Poster camera
Allowed:
media viewfinder + capture controls.

## Poster editor
Allowed:
frame + minimal chrome.

## Look editor
Allowed:
canvas + source/action tray.

## Wallet
Allowed:
balance;
- primary money actions;
- pending attention if real.

## Checkout
Allowed:
item;
delivery/payment summary;
total/pay should be reachable with short scroll.

## Seller home
Allowed:
Needs attention;
primary seller destinations.

## Seller Analytics
Allowed:
primary result;
period;
trend;
supporting KPI.

## Notifications
Allowed:
title;
optional mark-read/overflow;
notifications.
No six-filter wall.

---

# Review method

For each screenshot:
1. cover everything below first viewport.
2. ask reviewer “What is this screen for?”
3. ask “What would you tap next?”
4. ask “What is the most important object?”

If answers take more than 3 seconds, first viewport hierarchy failed.
