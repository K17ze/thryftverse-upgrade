# Copy, trust and decision psychology

## Product voice

Thryftverse should sound:
- concise;
- specific;
- calm;
- commercially literate;
- not impressed by its own technology.

## Replace architecture words with user words

Avoid:
- capability;
- pipeline;
- processing stage;
- advanced intelligence;
- market surface;
- agent runtime;
- canonical;
- premium;
- flagship;
- psychology;
in consumer UI.

Use the object/action:
- Send offer
- Order book
- Convert
- Share
- Search saved items
- Connect provider
- Allow access to saved items

## Trust placement

Trust is most effective near the decision it de-risks.

Examples:
- authenticity next to condition/media;
- returns/protection near Buy;
- issuer evidence near Co-Own identity;
- fees on trade review;
- agent permission immediately before action;
- payment total before Pay.

Do not make a generic “Trust” card and assume it solves every decision.

## Error copy
Must include:
1. what failed;
2. what remains safe/unchanged;
3. next action.

Example:
`Bid wasn't placed. Your balance wasn't charged. Try again.`

## Empty state copy
Describe the user state, not the component:
Bad: `No data found`.
Better: `No saved items yet`.

## Intelligent assistance
Never label a result “AI-powered” to make it seem valuable.
Use provenance:
- `Based on 18 sold items`
- `Similar to your saved Prada`
- `Suggested from this photo`

## Acceptance
Run a copy search for:
- flagship
- premium
- AI-powered
- intelligence
- psychology
- per spec
- per audit
- successfully
- processing
and review every consumer-visible occurrence.
