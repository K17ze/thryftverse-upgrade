## Rule for code agents

Before changing styles, write:
`ROLE: <role>`

Then answer:
1. Does this role need media?
2. What is its minimum information?
3. What is the user deciding?
4. Does containment aid that decision?
5. What can be hidden?

A patch that says only “make consistent with global design” is insufficient.
