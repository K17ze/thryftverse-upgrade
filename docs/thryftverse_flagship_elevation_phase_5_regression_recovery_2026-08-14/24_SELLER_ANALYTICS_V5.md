## Phase 4 flattening was correct here — mostly

Seller analytics should not return to an eight-card wall.

## But avoid becoming bland rows

Use:
- one primary outcome;
- real trend/chart if timeseries exists;
- 3–4 supporting KPIs;
- visual top listings;
- Needs attention.

## Backend evidence

No fake precision:
- conversion rate needs denominator;
- trends need previous window;
- top performer needs actual metrics.

If backend cannot provide timeseries, do not draw decorative sparkline.

## Seller Home

Needs attention before analytics:
- ship;
- reply;
- verification;
- auction action.

## Small flows

- bulk edit;
- vacation mode if supported;
- listing renew/relist;
- mark sold;
- archive;
- seller auction center;
- earnings;
- payout issue;
- analytics empty.

## Acceptance

Seller sees a decision, not a dashboard.
