## Phase 4 risk

A global flattening pass can make collections feel like utilities.
A personal collection should retain visual personality.

## Roles

Saved item = `personalCollection`.
Collection cover = `editorial/personalCollection`.
Management mode = `utility`.

Do not use one visual grammar for all three.

## Saved

Default:
visual grid.
Price can remain if purchase intent matters.

Price drops:
surface only when present.

## Collections

Cover:
2×2 or authored mosaic.
Title.
Count.
Privacy/collaboration state if relevant.

Avoid identical generic card covers.

## Create Collection

Small flow audit:
- name;
- cover derived from selected items;
- privacy;
- add selected items.

If no selected item:
create empty collection but show actionable empty state.

## Rename / delete

Context menu.
Delete confirms only because it is destructive.
Clarify whether saved items remain saved.

## Reorder

Drag in explicit Manage mode.

## Outfits / Looks

If the user creates Looks, use their visual thumbnails instead of representing them as generic saved-item lists.

## Acceptance

The user should recognize a collection by imagery before reading its title.
