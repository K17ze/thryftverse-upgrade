## Architecture assumed closed from Phase 3.1

Phase 5 focuses on presentation and integration consistency.

## Agent is a role, not a visual theme

Use:
- identity;
- purpose;
- status;
- access;
- approval.

Avoid:
- glowing robot cards;
- multiple AI badges;
- provider jargon in ordinary chat.

## Connections

Flat utility list:
provider → status → detail.

No giant connection hero unless health is broken.

## Approval

Human sentence:
`Negotiator wants to make an £85 offer`

Then:
`Review offer`

Never:
`Tier D capability offer.send requested`.

## Activity

Chronological verbs/objects.

## Small flows

- invalid key;
- revoke;
- change model;
- paused agent;
- provider offline;
- host offline;
- approval deny;
- approval expiry;
- stop task;
- session resume;
- permission edit.

## Acceptance

A nontechnical user can explain what an agent can see and whether an action has already happened.
