# Visual Language — Anti-Slop Rules

Synthetic UI is often recognizable by repeated rounded cards, symmetric feature grids, icon + title + subtitle tiles, decorative gradients, pills for every action, generic icon libraries everywhere, excessive explanatory copy, multiple horizontal carousels and animations added as “premium.”

## Rules

- Design the screen composition before choosing components.
- Canvas/content must dominate visual mass.
- Do not wrap every control in a card or glass surface.
- Use short labels; normal creation flows should not contain explanatory paragraphs.
- Use purpose-built glyphs for specialized creator operations, while keeping platform-familiar icons for close/back/gallery/delete.
- Brand color is for selection, Next/share and critical active state—not decoration.
- Bottom sheets are transient tools, not mini-pages.
- Creator should rarely show an illustrated empty state; acquisition itself prevents emptiness.
- Animation must explain cause, continuity or state. Otherwise remove it.

A screenshot with no context should look content-led, calm and intentional—not like a component-library demo.
