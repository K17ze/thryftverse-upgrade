# Media Selection → Editor Continuity

## Golden rule

**Choosing media is already an edit action.**

Once the user taps Done in the media browser, that media belongs on the canvas. Do not insert a “what next?” screen.

## Gallery → Look

Look mode → Gallery → select → Done → Look editor. One image becomes a usable composition immediately. Multiple images receive one good default layout automatically. Layout choice is available later if requested.

## Gallery → Poster

Poster mode → Gallery → select → Done → Poster editor. One item fills the stage. Multiple items preserve order as frames/clips.

## Camera → editor

Single photo: shutter flash → editor. Single video: recording stops → editor. Retake is achieved by back/delete rather than a forced action screen.

## Multi-capture exception

If the user explicitly enables Multi, the camera retains captures in a tray and Done sends the batch into the editor. This extra state is justified because the user requested batching.

## Perceptual continuity

The selected/captured media should appear to stay in place while editor chrome appears around it. Avoid decorative hero transitions, spinner pages or black/white flashes.

## Performance target

Media confirmation to visible editable canvas should feel immediate; project-local copying may continue behind the preview rather than blocking the handoff.
