# Look Flow Reconstruction

## Entry

Look is a camera mode. No Look landing page. Capture or gallery selection opens the Look editor directly.

## One image

Place it intelligently on a 4:5 canvas. Show a quiet contextual tool rail. No layout suggestions by default.

## Multiple images

Apply one competent default auto-composition and open the editor immediately. A Layout action lets the user change it later. Do not force five layout choices before the canvas.

## Items

Items belong inside Look. Tap Items to open Closet / Listings / Search in a bottom drawer. Tap or drag an item onto the canvas. The drawer temporarily owns the lower screen rather than coexisting with several rails.

## Layout

One layout chooser. Real previews. No simultaneous AutoLayoutBar + LayoutPreviewRail.

## Background

Canvas-level action accessed via empty-canvas context or More.

## Multi-select

Long press enters multi-select; bottom controls become Align / Front / Back / Delete.

## Emotional target

Look should feel like arranging a fashion/editorial board, not operating a design SaaS dashboard.
