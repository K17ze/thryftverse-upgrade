# Poster Flow Reconstruction

Poster is a camera mode, not a menu destination.

Single photo/video capture goes directly to the editor. Gallery selection does the same. Multiple media preserve order.

A single-photo Poster should show full canvas, Close, Undo, Next and a compact Text / Sticker / Music / Draw / More rail. It does not need a permanent timeline.

For video, keep the canvas dominant and expose a collapsed clip strip or Edit Clip affordance. Expand the full timeline only when editing time.

Multiple still frames can use swipe plus a transient frame tray. Avoid permanent project-management chrome unless the user is managing frames.

Effects should have one user-facing entry. AI effects can be a subsection. Templates remain secondary.
