# Tool Disclosure and Context

The bottom rail is a prediction of the next five actions, not a feature inventory.

## Look — nothing selected
Add Photo · Items · Text · Layout · More

## Look — media selected
Crop · Replace · Adjust · Cutout · More

## Look — text selected
Edit · Font · Color · Style · More

## Poster — nothing selected
Text · Sticker · Music · Draw · More

## Poster — photo selected
Crop · Adjust · Filter · Replace · More

## Poster — video selected
Edit Clip · Volume · Speed · Adjust · More

Timeline should not permanently reduce a single-photo canvas. Expand it for video, multiple clips or explicit Edit Clip.

Only one major bottom interaction surface can own the lower viewport at a time. Opening Items replaces the tool rail temporarily; opening Layout replaces it; opening Effects replaces it. Do not stack rails.

Pinning can be user-driven, but primary controls must not reorder automatically and destroy muscle memory.
