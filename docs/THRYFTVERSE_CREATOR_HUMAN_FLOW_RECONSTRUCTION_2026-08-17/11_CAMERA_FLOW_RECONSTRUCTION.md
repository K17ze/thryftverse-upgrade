# Camera Flow Reconstruction

The current camera has many meaningful capabilities: focus, shutter, gallery, flip, zoom, timer, grid, hands-free, speed metadata, multi-capture, green-screen settings and camera-effect metadata. The problem is not breadth; it is default exposure.

## Default visible
Close · Flash · Gallery · Shutter · Flip · Mode switch · minimal Zoom.

## Behind Tools
Timer · Grid · Hands-free · Speed · Green screen · Effects · Multi-capture.

## Single capture
Capture → editor. Remove forced quick-review for normal Look/Poster creation.

## Multi
Explicit Multi mode accumulates captures and shows a tray. Done → editor.

## Gallery
Tapping gallery opens the MediaBrowser directly and never returns through the intent dashboard.

## Camera effects
If an effect cannot be previewed live, do not visually imply it is already on the live camera. Either move it to the editor or clearly describe it as a post-capture treatment.

## Recording length
Do not couple source capture length to final story-frame length. Capture longer where safe; trim/segment later.
