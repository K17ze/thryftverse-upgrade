# Look / Poster / Search Switch

The switch should behave like a camera mode selector, not navigation tabs for three separate applications.

## Placement

Bottom of the camera, near the shutter and reachable by thumb. Keep it stable across modes.

## Visual treatment

Text-first, restrained and camera-native:
- unselected 60–70% white;
- selected full white / stronger weight;
- tiny underline or position indicator;
- no large rounded segmented-card container.

Support tap and optional horizontal swipe. Give one light haptic at mode boundary.

## Behavior

Switching mode keeps the live viewfinder on screen. Only the framing guide and relevant capture semantics change. No splash, no explanatory copy, no full-screen transition.

## Accessibility

Expose selectable items with selected state and names “Look mode”, “Poster mode”, “Search mode”. Never rely only on color.

## Acceptance

Opening creator shows camera and mode switch in the first state. Mode changes require one tap and no route transition. Gallery remains one tap away regardless of mode.
