## Core flow

1. Media
2. Identify
3. Condition/evidence
4. Price/terms
5. Delivery/transaction
6. Review

## Category schema

Backend owns required/recommended attributes.

Frontend renders appropriate input module.

## High-value mode

When category/value crosses a threshold:
add:
- verification;
- provenance;
- ownership;
- special shipping/inspection;
- professional/private seller obligations.

Do not front-load these forms on a low-value seller.

## Media guidance

Use category-specific capture list.

The camera can show a subtle shot checklist:
`Front`
`Back`
`Stamp`
`Corners`

This is a real competitive advantage because it improves search/trust/media quality.

## Seller preview

Before publish:
show exactly how:
- Home card;
- Product Detail;
- Storefront tile
will look.

This turns the seller into an art director without requiring design skills.

## AI assistance

Can suggest:
- title;
- category;
- shot missing;
- price range;
but never invent:
- provenance;
- serial;
- material;
- condition;
- authenticity.

All sensitive facts require seller confirmation/evidence.
