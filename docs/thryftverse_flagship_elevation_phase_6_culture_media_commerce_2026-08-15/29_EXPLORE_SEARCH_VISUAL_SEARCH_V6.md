## Explore

Default:
- Search;
- visual-search camera;
- high-quality content begins immediately.

Modes should be based on real user intent, not internal content taxonomy.

## Search

Global search:
- products;
- stores/people;
- collections;
- possibly category entities.

High-intent result card can be denser than Home.

## Visual Search

Flow:
1. camera/gallery;
2. select object/region;
3. retrieve visually similar inventory;
4. refine by category/brand/size/price/colour.

Pinterest's current visual-search behaviour validates image/object-as-query as a mature interaction pattern.

## Luxury categories

Visual similarity is helpful but never substitutes authenticity.

A similar watch result needs:
- reference/model facts;
- condition;
- trust.

## Search photo UI

Do not send user into the Poster/Look editor.
Visual Search shares acquisition, not composition.

## Seller/store search

Store card:
- identity;
- category/location;
- 3-item visual strip;
- trust/follow state.

No generic business directory cards.
