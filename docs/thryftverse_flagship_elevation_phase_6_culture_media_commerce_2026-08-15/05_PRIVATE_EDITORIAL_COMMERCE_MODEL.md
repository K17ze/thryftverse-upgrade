## The desired emotional shift

Most marketplaces begin with inventory.

Thryftverse should begin with **people, objects, taste and scenes** and become more transactional as intent rises.

This produces a three-layer model.

## Layer A — Culture
Poster, Look, profile grid, saved/editorial, creators, places, moments.

Primary question:
`Do I care about this?`

Metadata:
minimal.

## Layer B — Object
Tap a product/hotspot/listing.

Primary question:
`What exactly is this?`

Metadata:
identity, price, seller, condition, evidence.

## Layer C — Transaction
Buy, offer, bid, enquiry, authentication, shipping, escrow, inspection.

Primary question:
`Can I trust this transaction?`

Metadata:
explicit and precise.

## Why this can beat social-only selling

Social apps can generate demand, but commerce operators still need:
- inventory;
- pricing;
- availability;
- structured search;
- buyer protection;
- orders;
- payout;
- returns;
- authentication;
- staff/workflow;
- analytics.

Thryftverse should let the seller keep the visual culture **without leaving the platform for the transaction system**.

## Why this can beat marketplace-only apps

Traditional marketplace UX often makes every object look like inventory first.

Thryftverse can let sellers:
- publish a Drop;
- style a Lookbook;
- tell a product story;
- show a weekend/event/context;
- tag inventory into that content;
- convert the resulting attention into a trusted checkout.

## Core flywheel

`content → save/follow → storefront → listing → chat/offer → transaction → social proof → repeat customer`

## Rule

Never force every Poster/Look to be shoppable.

The cultural layer dies if every photograph feels like an advert.
