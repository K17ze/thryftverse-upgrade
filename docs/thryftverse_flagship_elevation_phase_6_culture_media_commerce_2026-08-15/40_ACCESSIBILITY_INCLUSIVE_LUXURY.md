## Principle

“Exclusive aesthetic” must not mean inaccessible software.

## Dynamic type

Utility/transaction screens fully support.

Creator artwork may maintain composition, but:
- editing controls scale;
- semantic text stored;
- viewer accessibility description available.

## Screen reader

Commerce card announces:
object + price + context.

High-value evidence:
source/status.

## Contrast

Creator text can intentionally be low contrast visually, but editor should warn/suggest:
`Improve readability`.

## Motion

Reduced motion removes:
- bounce;
- parallax;
- novelty text animation.

## Media

Alt text/caption:
- seller/creator supplied;
- optional suggestion reviewed by user.

## Touch

All core actions reachable without gesture-only knowledge.
