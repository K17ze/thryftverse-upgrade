# Two-layer art direction

Thryftverse needs two distinct visual layers.

## 1. Interface layer — quiet precision
Used for:
- navigation;
- settings;
- transaction flows;
- filters;
- account;
- seller operations;
- wallet.

Character:
- neutral;
- highly legible;
- restrained motion;
- Inter/current UI grotesk is acceptable.

## 2. Authored media layer — expressive
Used for:
- Poster;
- Look;
- storefront hero;
- editorials;
- Galleria;
- collection covers;
- campaign/drop presentation.

Character:
- multiple real type families;
- full-bleed media;
- composition;
- controlled overlays;
- optional cinematic texture;
- less standard card grammar.

Do not force expressive typography into Checkout, Wallet or security screens.

# Canvas colours

Default application:
- warm off-white rather than sterile #FFF where theme permits;
- near-black with subtle warmth rather than blue-black;
- borders slightly warm/neutral;
- semantic colours retain functional meaning.

The references already contain:
- cobalt water;
- tungsten amber;
- cream limestone;
- dark wood;
- black tailoring;
- silver/graphite cars.

The UI should not compete with those colours.

# Surfaces

Content surfaces:
- avoid visible card shells by default.

True object:
- media card;
- product;
- transaction review;
- approval;
- sheet.

Editorial:
- can break grid;
- can be edge-to-edge;
- can use asymmetry.

# Radius

Media in a profile/store grid:
- near-square/sharp or very small radius.

Marketplace discovery:
- small/medium radius.

Sheets:
- platform radius.

Do not give editorial photographs the same 16–24 px radius as generic SaaS panels.

# Icons

Use thin/simple icons.
No coloured circles unless state/action requires them.
Media-type marker can remain tiny and consistent.

# Motion

Motion character:
- fast;
- physical;
- low-amplitude;
- no “premium bounce” for normal information.

Creator direct manipulation can be springy because the object is being manipulated.

# Depth

The supplied media is often moody and high contrast. UI depth should come from:
- planes;
- overlays;
- temporary scrims;
- typography;
rather than box shadows.
