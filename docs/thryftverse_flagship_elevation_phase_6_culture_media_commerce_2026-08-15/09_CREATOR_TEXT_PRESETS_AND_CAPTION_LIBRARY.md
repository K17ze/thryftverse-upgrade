# Why this needs a product system

The target audience's screenshots often rely on no text at all. When text appears, it should feel like:
- a diary;
- a film note;
- a location/date;
- a magazine title;
- a subtle social caption.

The default editor should not encourage neon/glow/template clutter.

# Proposed initial presets

## 01 — Journal
Serif regular/italic.
32–52 pt depending canvas.
Short sentence.
No plate.

Example:
`late summer`

## 02 — Chapter
Large editorial serif.
60–110 pt.
Tight line height.
1–4 words.

Example:
`CAPRI`

## 03 — Clean
Modern sans medium.
20–42 pt.
Normal case.

Example:
`dinner after midnight`

## 04 — Archive
Mono.
13–24 pt.
Tracking 0.04em.
Metadata-like.

Example:
`MONACO / 23:48`

## 05 — Caption
Small clean sans.
14–20 pt.
Lower-left.
Optional soft dark scrim.

Example:
`the long way home`

## 06 — Label
Compact uppercase.
Neutral translucent plate.
Use for place/object.

Example:
`VILLA BELLEROSE`

## 07 — Statement
Heavy grotesk.
56–120 pt.
Very short.

Example:
`NO PLANS`

## 08 — Note
Restrained italic/handwritten option only after art review.

# Text backgrounds

Default options:
- None
- Soft shadow
- Dark plate
- Light plate
- Highlighter

Novelty:
- neon/glow/outline
hidden behind Effects.

# Typography editing

- pinch adjusts scale naturally;
- double tap edits;
- text toolbar changes family/preset;
- baseline metrics stable;
- automatic safe zones;
- snapping;
- colour picker sampled from image;
- eyedropper if supported.

# Dynamic contrast

Offer:
`Improve contrast`
which chooses:
- shadow;
- plate;
- white/black suggestion.

Do not silently change the user's art.

# Commerce tags

Commerce tag typography should always use UI sans, not creator font, so price/title remain trustworthy and readable.

# Accessibility

Published decorative text can have:
- stored text semantic content;
- caption/alt equivalent;
- screen reader skips decorative duplicates.

# Licensing

Only bundle fonts with verified application distribution rights.
Prefer permissive/static families for cross-platform consistency.
