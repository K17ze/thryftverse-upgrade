## Mission

Do not “make the app look luxury.”

Build a culturally desirable, high-fidelity, trustworthy social-commerce system where:
- content looks better than the UI around it;
- Creator feels native and continuous;
- sellers can build real storefronts;
- high-value objects gain appropriate evidence/transaction infrastructure;
- ordinary resale remains simple.

## Hard constraints

1. No mass global style refactor.
2. No black-and-gold luxury theme.
3. No generic serif across utility UI.
4. No fake cutout.
5. No fake video editing.
6. No fake authentication badge.
7. No fake escrow language.
8. No product ranking based on inferred wealth/class/protected traits.
9. No destructive client compression without measured reason.
10. No thumbnail request using layout dp as physical pixels.
11. No creator “font” preset implemented only as an Inter weight/italic if it claims a distinct typographic personality.
12. No Phase 6 completion without native visual release proof.
