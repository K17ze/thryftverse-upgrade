## Do not rank people by perceived wealth

Never infer protected/socioeconomic identity from images and use it to privilege access.

## Rank objects/content using product signals

Potential:
- user follows;
- saves;
- category interest;
- visual similarity;
- freshness;
- seller quality;
- transaction performance;
- availability;
- price band explicitly selected;
- content quality;
- diversity;
- novelty.

## High-quality media signal

Media quality can influence presentation/ranking carefully:
- sufficient resolution;
- non-broken;
- useful object visibility.

Do not reward only studio photography; candid/editorial culture is part of the product.

## Mixed feed

Balance:
- social Poster;
- Looks;
- products;
- editorials;
- live auctions
based on intent.

## Session modes

A user browsing after tapping a Birkin may get more object-commerce content.
A user browsing friends' Poster should not be abruptly converted into a shopping feed.

## Visual similarity

Pinterest-style visual search/recommendation is relevant:
- query object;
- colour;
- silhouette;
- style;
- category.

Results must remain inventory-truthful.
