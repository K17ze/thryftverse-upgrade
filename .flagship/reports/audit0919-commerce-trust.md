## Adversarial notes

1. **Integration suite is conditional.** `productionInvariants.test.ts` is the strongest evidence in this audit, but it self-skips when Postgres is unreachable (`requireDb`, lines 230-236). If CI never sets `DATABASE_URL`, all R10-R13 proofs are latent. Confirm `backend-ci.yml` provisions a service DB for this suite.
2. **Mirror-vs-handler gap.** The race/idempotency proofs re-implement the route SQL rather than exercising the HTTP handler; a future route refactor that drops `FOR UPDATE` would not fail these tests. `routes.test.ts`/`testApp.ts` integration coverage should be checked for a handler-level duplicate-checkout test.
3. **P0-12 external URL** is a hard store-compliance gap for Android (Google Play requires an external deletion link).
4. **P0-15** lacks the two artifacts most likely to be asked for in review: a MASVS mapping doc and CI secret scanning.
5. **R29** is honest-but-incomplete: fees are server-computed on PDP, shipping/taxes only after a destination exists — a "landed total" claim on the PDP would currently be overstated.
6. **R82** device-fingerprint linkage is real but single-signal; determined attackers rotating headers evade it (acknowledged in-code).
7. **P0-10** payout eligibility is enforced at settlement/admin-approve, not at request creation — acceptable fail-closed posture, but request-time UX will allow creating a request that later stalls.
