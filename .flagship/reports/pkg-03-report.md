| FIN-02 (High) — GBP→1ZE conversion unsound | Single versioned quote path `resolveCoOwnSettlementRateContext` + `computeCoOwnSettlementUnits` (`lib/pricingEngine.ts:696-834`, prior pass): GBP → USD anchor at par → 1ZE minor units, `COOWN_SETTLEMENT_QUOTE_VERSION = 'coown_gbp_to_1ze_v1'`; payer leg `ceil`, payee leg `floor`, dust absorbed platform-side. | FIN-05 (High) — trade/DRIP bypass segment accounting | DRIP wallet legs replaced direct `wallets`/`wallet_ledger` writes with `debitCoOwnOnezeUnits`/`creditCoOwnOnezeUnits` (`coOwnDripExecutionHandler.ts:357-395`). ## Seams / notes for the orchestrator

- **Migration numbering**: `331` was next-free at write time; `330` belongs to another package's in-flight work. Renumber if a collision lands.
- **Lockup scope decision**: DRIP reinvestment buys from the issuer's primary pool and is deliberately NOT lockup-gated (secondary-resale semantics; blocking would strand owed distributions). Flag if the policy intent was broader.
- **workerRuntime seam**: DRIP/alert workers import `db` singleton — tests patch `db.query`/`db.connect`; drain tests stub `workerRuntime.queueUserNotification` via `node:module` register (same convention as `safetyBuyerRemovalNotice.test.ts`) so no redis/queue connections open.
- **PATCH re-arm**: seq only increments when `triggered_at` is cleared (true re-arm); plain activate/deactivate toggles don't churn the counter.
- DRIP during missing FX config stays `settled` and retries each pass — deliberate; an ops alert on repeated `CO_OWN_FX_RATE_UNAVAILABLE` would be a reasonable follow-up.
