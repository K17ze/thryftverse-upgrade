## Adversarial findings worth flagging

1. **OTA signing is currently unprovisionable as committed.** `app.config.js:219,227-236` requires `frontend/keys/update-certificate.pem`; `check-release-config.mjs:40-46` requires it committed; `.gitignore:32` (`*.pem`) + `.gitignore:70` (`frontend/keys/`) make committing it impossible without `git add -f`. `frontend/certs/` contains only a README that prescribes a *different* path (`certs/update-certificate.pem`) than the code reads. Until a cert is force-added or the ignore rules fixed, every production EAS build and OTA publish fails closed — safe, but the pipeline cannot ship.
2. **`settings.yml` required-check contexts are stale.** They name contexts like `Frontend CI / typecheck` that no current job emits; applied as-is, `main` would be unmergeable (or the check would never satisfy). Needs correction to actual job names (e.g. `TypeScript typecheck`, `API build, unit, migration, integration`).
3. **No "checks passed on this SHA" verification anywhere in the release path.** The production gate is a manual environment approval; nothing asserts the tag's CI state. Combined with (2), a tag can be pushed on a red SHA and only a human blocks release.
4. **`deriveServeMode` mislabels degraded backend as `cold_start`** (`search.ts:29-31`) — when Meilisearch is down and the adapter serves in-memory, `serveMode` reports `cold_start` rather than degraded. `retrievalMeta.degraded:true` still discloses it, so this is a labeling inconsistency, not a hidden fallback.
5. **`sloTracker.ts` is unwired dead code** — its own docblock gives wiring instructions that were never applied. The R88 SLO story is a Grafana JSON + Prometheus rules file only; no error-budget data is produced by the app.
6. **`npm run chaos:smoke` referenced in `CHAOS_RUNBOOK.md:51` does not exist** in `backend/api/package.json`.
7. **Queue backlog alert approximates depth from job rates**, not BullMQ `waiting` counts — it detects sustained in>out imbalance, not absolute backlog; DLQ depth itself has no alert (only purge).
