## Purpose

This pack is an evidence-led audit and implementation brief for the three Thryftverse product-detail families:

1. Direct listings
2. Auctions
3. Co-Own assets

It covers visual quality, information architecture, image/video handling, role and lifecycle states, frontend/backend truth, accessibility, verification, and implementation sequencing. It does not call the branch flagship or device-verified: no completed branch-native screenshot matrix or populated closure report was found.

## Non-negotiable interpretation rule

A source-level pass is not a rendered visual pass. A mocked state is not a supported backend state. A successful happy path is not transaction closure. Every completion claim must link to code, a runtime test, and—where visual behaviour is involved—a named native capture.
