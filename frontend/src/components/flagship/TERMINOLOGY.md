# ThryftVerse Terminology Source

## Canonical terms
- **Listing** — an item for sale (not "product", not "post")
- **Seller** — a user who has listed items (not "vendor", not "merchant")
- **Buyer** — a user who purchases (not "customer", not "purchaser")
- **Offer** — a proposed price below the listing price (not "bid" except in auctions)
- **Bid** — only used in auction contexts
- **Order** — a completed purchase (not "transaction" in UI copy)
- **Transaction** — only used in wallet/financial contexts
- **Saved** — items in a user's collection (not "wishlist", not "favorites")
- **Inbox** — the conversation list (not "messages", not "chats")
- **Conversation** — a single chat thread (not "chat", not "thread")
- **Message** — a single sent item in a conversation
- **Payout** — money sent to a seller's bank (not "withdrawal")
- **Checkout** — the purchase flow (not "payment", not "cart")
- **Cart** — only used if a multi-item cart exists (currently single-item checkout)

## State copy rules
- Never use "Something went wrong" — say what went wrong
- Never use "Please try again" without explaining what will happen
- Never use exclamation marks in error states
- Never blame the user ("You are offline" is OK; "You lost connection" is not)
- Always offer a specific recovery action when possible
- Use sentence case, not title case
- Keep titles under 40 characters
- Keep subtitles under 80 characters
- One action per state — do not offer three buttons
