# Chic, Minimal Visual Polish System

## The target

Thryftverse should feel *confidently edited*: premium marketplace utility with Instagram-level action clarity and Pinterest-level content dominance.

It should not imitate another app pixel-for-pixel.

## 1. Reduce cardification

Use a card only when it represents:
- an independent object;
- a floating/interactable surface;
- a grouped block that benefits from containment.

Do not card:
- ordinary settings sections;
- every product-detail fact;
- every order timeline stage;
- each label/value pair.

Prefer:
- whitespace;
- 1px/hairline separators used sparingly;
- typography;
- subtle tonal surface changes.

## 2. Radius discipline

Define role-based radii:
- media;
- sheet;
- control;
- compact chip;
- card.

Do not let individual screens invent 10, 12, 14, 16, 18, 20, 24 radii because they “look nice”.

## 3. One accent, many neutrals

Brand accent is for:
- primary next action;
- selected control;
- true link;
- active state.

Do not use brand colour to decorate passive section titles, icons and borders simultaneously.

## 4. Typography

A transactional screen rarely needs more than:
- strong state/title;
- body/primary value;
- muted metadata/caption.

Avoid five weights and four grey levels within a 200pt region.

## 5. Iconography

- one icon family/style;
- consistent stroke/optical weight;
- icon size and target size are separate;
- no grey circular icon backgrounds by default;
- no icon when text alone is clearer.

## 6. Buttons

- one dominant solid CTA;
- secondary quiet;
- destructive separated;
- fewer full-width buttons;
- action sheets for true secondary choices;
- no “button stack” where rows or inline actions would be calmer.

## 7. Pills/chips

Use pills for:
- filters;
- compact binary/state selectors;
- short status tokens when state cannot be communicated through adjacent text.

Do not turn metadata, labels, trust facts and prices into pills.

## 8. Shadows

Use elevation to communicate layering, not “premium”.
- modal/sheet/floating bar: yes;
- every primary button: generally no;
- static cards: minimal/none in light theme if boundary is obvious.

## 9. Motion

Motion should explain:
- where content came from;
- what changed;
- what is selected;
- whether an action succeeded.

No motion merely because flagship apps animate.

Recommended feel:
- quick;
- low-amplitude;
- interruptible;
- reduced-motion aware.

## 10. Dense but breathable

Instagram and Pinterest can look simple because spacing is consistent, not because every component is huge.

Target:
- compact rows;
- clear section rhythm;
- enough touch target;
- less empty card padding;
- content-width hierarchy.

## Visual lint questions

For every screen:
1. Can any border disappear?
2. Can two cards become one section?
3. Can one title disappear because context already says it?
4. Are two actions competing?
5. Is an icon decorative noise?
6. Is the primary content larger than the UI around it?
7. Does a badge exist without changing a decision?
8. Can a secondary detail move behind disclosure?
9. Does dark mode preserve hierarchy without turning every outline bright?
10. Does the screen still read correctly in grayscale?
