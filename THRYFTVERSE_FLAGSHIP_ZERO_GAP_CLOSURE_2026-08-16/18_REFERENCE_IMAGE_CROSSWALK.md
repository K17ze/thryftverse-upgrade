# Supplied Reference Image Crosswalk

The screenshots supplied with this project are useful as *quality references*, not pixel-copy specifications.

## Settings / account references
Files include settings/account screenshots from Instagram/Depop-like surfaces.

Extract:
- grouped semantic rows;
- restrained icon use;
- minimal container framing;
- clear chevrons;
- hierarchy through section labels + spacing;
- compact row density with comfortable targets.

Apply:
- Settings;
- seller shipping preferences;
- account/payment/postage sections.

## Edit profile / profile references

Extract:
- identity content has visual priority;
- management actions are compact;
- metrics and grids have clear alignment;
- profile does not become a settings dashboard.

Apply:
- public profile;
- edit profile;
- seller public/private separation.

## Inbox/message references

Extract:
- search/filter close to message list;
- avatar + sender + preview + timestamp creates strong scan hierarchy;
- transaction context can appear without dominating chat;
- composer stays visually stable.

Apply:
- Inbox;
- Chat transaction strip;
- offer/order messages.

## Pinterest / saved / overall references

Extract:
- image canvas dominates;
- masonry/visual collections explain themselves;
- UI chrome stays quiet;
- actions appear near content rather than in giant control panels.

Apply:
- Discover;
- Saved Closet;
- related items on Product Detail.

## Product-detail references

Extract:
- hero media first;
- title/price/condition compressed;
- one dominant purchase CTA;
- secondary offer/save below;
- detail/protection progressively disclosed;
- recommendation content follows decision-critical data.

Apply:
- Product Detail;
- auction/co-own variants while keeping mode semantics distinct.

## Guardrail

Do not homogenise all modes. “Uniform quality” means shared spacing, actions, typography and transition standards; it does **not** mean normal listing, auction, co-own, seller hub and messaging should become identical layouts.
